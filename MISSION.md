# Mission: Learn GitHub in 3 Days

## Why

You need to become productive with GitHub — for version control, collaboration,
publishing, and CI/CD — within a short timeframe (2–3 days, 1.5 hr each).

You're working with a VPS, deploying apps, and want to move beyond copy-paste
tutorials to a workflow you can repeat on every project.

## Goal

By the end of this course you should be able to:

- Init a Git repo, commit changes, branch, merge, and push to GitHub
- Clone, fork, create pull requests, and review code on GitHub.com
- Use GitHub Issues + Projects for task tracking and planning
- Set up a GitHub Actions CI/CD pipeline that deploys to your VPS
- Navigate the GitHub.com UI confidently (repos, settings, branches, history)

## Schedule

| Day | Topic                          | Time    | Key Outcome                          |
|-----|-------------------------------|---------|--------------------------------------|
| 1   | Git + GitHub Foundations       | 1.5 hr  | Push code, clone, branch, merge      |
| 2   | Collaboration + GitHub UI      | 1.5 hr  | PRs, forks, issues, reviews          |
| 3   | CI/CD + Publishing (Actions)   | 1.5 hr  | Deploy to VPS via GitHub Actions     |

## Deliverable

A deployed web app on your VPS triggered by a push to GitHub `main` — built
from scratch during Day 3, going from zero to live.
