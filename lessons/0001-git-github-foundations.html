Day 1 — Git + GitHub Foundations

~30 min read + 60 min hands-on

Goal: Create your first repo, make commits, and push to GitHub. By the end you'll have a live repo at https://github.com with your code on it.

What is Git? What is GitHub?

Git is a version-control system — it saves snapshots of your files so you can go back, compare changes, and work with others without overwriting each other's work.

GitHub is a web service that hosts Git repos online. It adds a UI for code review, issue tracking, and collaboration on top of Git.

Git runs on your computer. GitHub is the website where you upload your Git repo so others can see it.

Step 1 — Create your first repo

mkdir my-first-repo && cd my-first-repo
echo "# My First Repo" > README.md
git init
git add README.md
git commit -m "Initial commit"

Step 2 — Push to GitHub

Create the repo on GitHub, then link and push:

gh repo create my-first-repo --public --source=. --push

This single command creates the repo on GitHub, adds the remote, and pushes your local main branch.

Visit https://github.com/<your-username>/my-first-repo — you should see README.md on the page.

Step 3 — Make a second commit

echo "Some content" > notes.txt
git add notes.txt
git commit -m "Add notes file"
git push

Key concepts in 60 seconds

CommandWhat it does
git initCreates a Git repo in the current folder
git add <file>Stages a file for the next commit
git commit -m "msg"Saves a snapshot in the repo history
git pushUploads commits to GitHub
git pullDownloads commits from GitHub
gh repo createCreates a repo on GitHub from the CLI

Try this at home

  • Create a repo called hello-github with a hello.py that prints your name
  • Commit and push it to GitHub
  • Visit the GitHub URL in your browser — confirm the file is there
  • Add a new line to hello.py, commit, and push again

    • ⏱ Time check: If the above felt natural, you're ready for Day 2. If git push or git commit felt confusing, re-read the GitHub Hello World guide.
