Day 3 — CI/CD with GitHub Actions

~30 min read + 60 min hands-on

Goal: Create a GitHub Actions workflow that automatically deploys a small app to your VPS when you push to main.

What is GitHub Actions?

GitHub Actions runs code automatically — when you push, open a PR, on a schedule, or manually. The code lives in .github/workflows/*.yml.

The plan

  • Create a tiny web app (Node.js "Hello World" server)
  • Push it to a GitHub repo
  • Add a workflow that SSHes into your VPS and deploys it
  • Make a change → push → watch it deploy automatically

    • Step 1 — The app

    npm init -y
npm install express

    Create app.js:

    const express = require('express');
const app = express();
const PORT = process.env.PORT || 3000;

app.get('/', (req, res) => {
  res.send('Hello from GitHub Actions! Deployed automatically.');
});

app.listen(PORT, () => {
  console.log(`Server running on port ${PORT}`);
});

    Step 2 — Push to GitHub

    npm init -y
npm install express
echo "node_modules/" > .gitignore
git init
git add .
git commit -m "Add express app"
gh repo create learn-github-actions --public --push

    Step 3 — Build the workflow

    Create .github/workflows/deploy.yml:

    name: Deploy

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Deploy to VPS
        uses: appleboy/ssh-action@v1.1.0
        with:
          host: ${{ secrets.VPS_HOST }}
          username: ${{ secrets.VPS_USER }}
          key: ${{ secrets.SSH_KEY }}
          script: |
            cd /var/www/myapp
            git pull
            npm install
            npm restart  # or pm2 restart app

    Step 4 — Set secrets on GitHub

    Add the SSH key and VPS info to your repo settings:

    gh secret set VPS_HOST --body "123.45.67.89"
gh secret set VPS_USER --body "ubuntu"
gh secret set SSH_KEY < ~/.ssh/id_rsa

    Step 5 — Test the deployment

  • On your VPS: mkdir -p /var/www/myapp && cd /var/www/myapp && git init && git remote add origin https://github.com/<you>/learn-github-actions.git
  • Push to main on GitHub
  • Go to the Actions tab — watch the workflow turn green
  • SSH into your VPS — confirm the app is running (curl localhost:3000)
  • Edit app.js — change the message, push, and watch it redeploy

    • Try this at home

    Deploy your my-first-repo (from Day 1) as a static site using the same pattern — just swap git pull for git pull && echo "deployed" in the script.
